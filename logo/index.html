Why this direction · Research

Flat first

Flat logos reproduce cleanly at any size and look native on screens, so the gradient is gone. All three use solid colour only.

Superside

Design small first

A mark should be tested at favicon size before anything else. Option 1 holds at 16 px. Options 2 and 3 need 24 px, or a simplified version for favicons.

Superside

Own the category

LLumar, a major window film brand, already uses a semicircle with a sun. These symbols use what is specific to ASC: glass, windows and the Atlantic.

1000 Logos

Character in the type

Serifs are returning and brands are moving away from generic sans serifs. Option 3 follows that, and it keeps a link to the serif in the current logo.
